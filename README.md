# ⭐ Social Proof Section

A fully responsive **Social Proof Section** built using **HTML** and **CSS**, inspired by a challenge from Frontend Mentor. This component showcases customer ratings and testimonial cards in a clean, modern design that adapts beautifully to mobile, tablet, and desktop screens.

## 📌 Overview

The layout includes:

-   ⭐ Five‑star rating boxes
-   👥 Three customer testimonial cards
-   📝 Clean typography and color‑balanced UI
-   📱 Fully responsive layout built with Flexbox & Grid
-   🎨 Custom CSS variables for consistent styling

The project recreates a professional‑looking social proof section commonly used in landing pages and marketing websites.

## 🛠️ Technologies Used

-   **HTML5**
-   **CSS3** (Flexbox, Grid, Custom Properties)
-   Responsive design using **media queries**
-   Google Fonts (**League Spartan**)

## 🎯 Purpose

This project is part of my **Front-End development practice**, focusing on building clean layouts and improving responsive design skills. The goal was to recreate a polished Social Proof UI section using only **HTML** and **CSS**, without any frameworks.

## 💡 What I Learned

-   Structuring components using **Flexbox** and **Grid** together
-   Improving layout responsiveness using media queries
-   Working with **CSS variables** for cleaner theming
-   Enhancing readability and spacing in UI components
-   Creating mobile-first, tablet-friendly UI sections
